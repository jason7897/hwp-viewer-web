한글 표를 엑셀로 옮기기

한글로 만든 견적서·명단·실적표를 엑셀에서 계산하려는 상황입니다. 한컴오피스가 없어도 됩니다. 다만 붙여넣는 방법에 따라 칸이 깨지느냐 마느냐가 갈립니다. 안 깨지는 순서를 적었습니다.

2026-10-07 작성

가장 잘 되는 순서

  1. 홈에 hwp·hwpx 파일을 끌어다 놓습니다
  2. 내용이 표시되면 「HTML로 내려받기」를 누릅니다
  3. 받은 .html 파일을 더블클릭해 브라우저로 엽니다
  4. 표를 마우스로 드래그해 선택하고 복사합니다
  5. 엑셀에 그대로 붙여넣습니다
왜 HTML을 거치나. 엑셀은 복사된 내용이 HTML 표일 때 그것을 표로 알아듣고 칸을 나눠 넣습니다. 화면에서 바로 긁어 붙이면 줄바꿈 단위로만 들어가 한 칸에 몰리는 일이 생깁니다. 한 단계를 더 거치는 대신 칸이 유지됩니다.

다른 방법 — 상황에 따라

상황방법결과
표를 엑셀에서 계산해야 함HTML로 내려받아 복사·붙여넣기칸이 가장 잘 유지됨
값만 빠르게 빼면 됨「텍스트로 내려받기」칸이 공백으로 구분됨. 엑셀의 「텍스트 나누기」로 나눔
문서 전체를 옮김「Word(.docx)로 저장」워드에서 표를 복사해 엑셀로
모양만 보면 됨PDF로 저장편집은 안 되지만 모양이 그대로

칸이 어긋났을 때

여러 칸이 한 칸에 몰렸습니다

HTML을 거치지 않고 붙여넣었을 때 흔합니다. 위의 순서대로 다시 해보세요. 그래도 몰린다면 텍스트로 내려받아 「텍스트 나누기」를 쓰는 편이 빠릅니다. 엑셀에서 붙여넣은 열을 선택하고 데이터 → 텍스트 나누기 → 「공백」으로 구분하면 됩니다.

병합된 칸이 풀려서 밀렸습니다

한글에서 여러 칸을 합쳐 쓴 표는 엑셀로 옮길 때 그 구조가 그대로 가지 않는 경우가 있습니다. 병합이 많은 표는 값만 옮기고 표는 엑셀에서 새로 만드는 편이 빠릅니다. 씨름하는 시간이 보통 더 깁니다.

숫자가 글자로 들어갔습니다

1,000 처럼 쉼표가 들어간 숫자나 앞에 공백이 붙은 숫자는 엑셀이 글자로 받습니다. 계산이 안 되면 해당 열을 선택해 데이터 → 텍스트 나누기 → 마침을 누르면 숫자로 바뀌는 경우가 많습니다.

옮긴 뒤에는 합계를 한 번 맞춰보세요. 표를 형식 간에 옮기면 빈 칸이 생기거나 행이 밀리는 일이 있습니다. 원본 문서의 합계와 엑셀의 합계가 같은지 확인하는 것이 가장 빠른 검산입니다.

반대 방향 — 엑셀 표를 한글로

엑셀에서 범위를 복사해 한글 문서에 붙여넣으면 표로 들어갑니다. 다만 이 사이트는 한글 문서를 만들어 내지는 못합니다 — 읽고 다른 형식으로 내보내는 것까지만 합니다. 한글 문서를 직접 편집해야 한다면 한컴 공식 제품이 필요합니다.

자주 묻는 것

엑셀이 없어도 되나요?

구글 스프레드시트에도 같은 방식으로 붙여넣을 수 있습니다. HTML 표를 복사해 붙이면 칸이 나뉘어 들어갑니다.

표가 여러 개인 문서는요?

내려받은 HTML에 표가 전부 들어 있습니다. 필요한 표만 골라 드래그해 복사하세요.

파일이 서버로 올라가나요?

올라가지 않습니다. 문서를 읽고 내보내는 작업이 브라우저 안에서만 일어납니다. 회사 실적표나 명단처럼 밖에 나가면 안 되는 문서도 그대로 쓸 수 있습니다.

표 안의 그림도 옮겨지나요?

그림은 표 구조와 함께 옮겨지지 않을 수 있습니다. 값 위주의 표에 맞는 방법입니다.
