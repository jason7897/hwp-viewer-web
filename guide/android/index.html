hwp 뷰어 안드로이드

갤럭시에서 받은 한글파일이 안 열릴 때. 앱을 새로 깔지 않고 지금 바로 여는 방법부터 정리했습니다.

2026-09-21 작성

안드로이드는 hwp 형식을 기본으로 읽지 못합니다. 그래서 메일이나 카톡으로 받은 한글파일을 눌러도 「이 파일을 열 수 있는 앱이 없습니다」가 뜨거나, 파일 관리자에서 회색 아이콘만 보입니다.

방법은 둘입니다. 둘 다 무료고, 상황에 따라 나은 쪽이 다릅니다.

지금 바로 열어보기 →
앱 설치 없이 크롬에서 hwp 파일을 엽니다. 파일은 서버로 올라가지 않습니다.

방법 1. 크롬에서 바로 열기 (설치 없음)

먼저 파일을 저장합니다

  • 메일 첨부파일 — 첨부파일 옆 내려받기 아이콘을 누르면 「다운로드」 폴더에 저장됩니다
  • 카카오톡 — 파일을 누른 뒤 하단의 저장 아이콘을 누릅니다. 카톡 안에서 미리보기가 안 되는 것은 정상입니다
  • 문자·메신저 — 대체로 같은 방식으로 저장됩니다

그다음 브라우저에서 엽니다

  1. 크롬이나 삼성 인터넷으로 HWP 뷰어에 접속합니다
  2. 화면 가운데 상자를 누릅니다
  3. 파일 선택 화면에서 조금 전 저장한 hwp 파일을 고릅니다 (보통 「다운로드」에 있습니다)
  4. 문서가 바로 나타납니다. 필요하면 PDF나 Word로 저장합니다
파일이 어디로도 전송되지 않습니다. 문서를 읽고 화면에 그리는 과정이 전부 휴대폰 안에서 일어납니다. 업로드 방식의 변환 사이트와 달리 파일이 기기 밖으로 나가지 않습니다.

방법 2. 한컴오피스 Viewer 앱 설치

한글을 만든 한글과컴퓨터가 내놓은 무료 뷰어 앱이 플레이스토어에 있습니다. 「한컴오피스 Viewer」를 검색하고 제작사가 한글과컴퓨터인지 확인한 뒤 받으면 됩니다.

한 번 설치해 두면 첨부파일을 누르는 것만으로 바로 열립니다. 한글 문서를 자주 받는다면 이쪽이 편합니다.

그래도 브라우저가 나은 경우

  • 앱을 깔고 싶지 않거나 저장 공간이 부족할 때
  • PDF·Word로 바꿔야 할 때 — 뷰어는 보기 전용입니다
  • 내 폰이 아닐 때
  • 딱 한 번만 확인하면 될 때

파일이 안 보일 때

파일 선택 화면에서 hwp가 안 보이는 경우가 있습니다. 아래를 확인해 보세요.

  • 「최근 항목」 대신 폴더로 들어가기 — 왼쪽 위 메뉴에서 「다운로드」를 직접 고르면 보입니다
  • 파일 형식 필터 — 「모든 파일」로 되어 있는지 확인하세요
  • 저장이 덜 됐을 수 있음 — 파일 크기가 0에 가깝다면 다시 받아 보세요

자주 묻는 것

갤럭시 「내 파일」에서 눌렀는데 안 열립니다

안드로이드가 hwp 내용을 해석하지 못해 생기는 현상입니다. 파일이 손상된 것이 아니니 그대로 두고, 브라우저 뷰어나 한컴 뷰어 앱으로 여시면 됩니다.

hwpx도 되나요?

됩니다. hwp와 hwpx 모두 지원합니다. 구버전 프로그램에서 hwpx가 안 열리는 경우가 많은데, 여기서는 둘 다 열립니다.

휴대폰에서 PDF로 저장하려면?

문서를 연 뒤 「PDF로 저장」을 누르면 인쇄 창이 뜹니다. 프린터 선택에서 「PDF로 저장」을 고르면 됩니다.

데이터가 많이 쓰이나요?

문서를 해석하는 코드를 처음 한 번 내려받습니다. 그 뒤로는 파일을 열 때마다 통신이 발생하지 않습니다. 파일을 서버로 올리지 않기 때문입니다.

같이 보면 좋은 글

  • 아이폰·아이패드에서 hwp 파일 여는 법
  • 맥북에서 한글파일(hwp) 여는 법
  • 한글파일을 PDF로 저장하는 법

이 문서는 한글과컴퓨터와 관련이 없습니다. 제품명은 각 소유자의 상표입니다.
