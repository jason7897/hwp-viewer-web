hwpx 파일 열기

분명 한글 프로그램이 깔려 있는데 hwpx만 안 열립니다. 파일이 잘못된 게 아니라 대부분 이유가 하나입니다.

2026-09-21 작성

받은 파일이 .hwpx인데 더블클릭해도 열리지 않거나, 「연결 프로그램 없음」이 뜨거나, 한글을 실행해도 「지원하지 않는 형식」이라고 나오는 경우가 있습니다.

원인은 대개 프로그램이 오래됐기 때문입니다. hwpx는 비교적 나중에 생긴 형식이라, 예전 버전의 한글이나 오래된 뷰어는 이 형식을 모릅니다. 파일이 손상된 것이 아니므로 보낸 사람에게 다시 요청할 필요는 없습니다.

설치 없이 브라우저에서 hwpx를 엽니다. PDF·Word로도 바꿀 수 있습니다.

hwp와 hwpx는 뭐가 다른가

둘 다 한글 문서지만 안쪽 구조가 완전히 다릅니다.

hwphwpx
구조한컴 고유의 이진(binary) 형식압축 파일 안에 XML 문서가 들어 있는 개방형 구조
공개 여부형식 문서가 공개돼 있으나 해석이 까다로움구조가 공개돼 있어 다른 프로그램이 다루기 쉬움
구버전 호환넓음좁음 — 오래된 프로그램은 못 읽음
쓰임여전히 가장 널리 쓰임공공기관 문서에서 늘어나는 추세

쉽게 말하면 hwpx는 한글 문서를 "열어볼 수 있게" 새로 포장한 형식입니다. 그래서 요즘 도구들은 오히려 hwpx를 더 잘 다루고, 반대로 옛날 프로그램은 아예 모릅니다.

해결법 1. 브라우저에서 열기 (설치 없음)

가장 빠릅니다. 프로그램을 새로 받거나 업데이트하지 않아도 됩니다.

  1. HWP 뷰어에 접속합니다
  2. hwpx 파일을 끌어다 놓거나 눌러서 선택합니다
  3. 문서가 바로 보입니다. 필요하면 PDF나 Word(.docx)로 저장합니다
파일이 서버로 전송되지 않습니다. hwpx를 읽고 화면에 그리는 과정이 전부 이용자의 브라우저 안에서 일어납니다. 업로드 방식의 변환 사이트와 달리 파일이 컴퓨터 밖으로 나가지 않습니다.

맥·아이폰·안드로이드에서도 똑같이 동작합니다. hwp와 hwpx 둘 다 지원합니다.

해결법 2. 한글(한컴오피스) 최신 버전으로 업데이트

hwpx를 앞으로도 계속 받을 예정이고 직접 편집해야 한다면 이 방법이 맞습니다. 한컴오피스를 최신 버전으로 올리면 hwpx를 정상적으로 열고 저장할 수 있습니다.

회사나 기관 PC라 임의로 업데이트할 수 없는 경우가 많은데, 그럴 때는 아래 방법이 현실적입니다.

해결법 3. hwpx를 hwp로 바꿔 달라고 요청

보낸 사람이 최신 한글을 쓰고 있다면, 「다른 이름으로 저장」에서 형식을 hwp로 골라 다시 보내 달라고 하면 됩니다. 받는 쪽 환경이 오래됐다는 걸 알려주면 대부분 바로 처리해 줍니다.

다만 매번 요청하기는 번거로우니, 급할 때는 브라우저로 열어 내용을 먼저 확인하는 편이 빠릅니다.

이런 경우는 다른 문제입니다

프로그램 버전 때문이 아니라 파일 자체의 문제일 수도 있습니다. 화면에 아래 같은 안내가 뜬다면 원인이 다릅니다.

  • 암호가 걸린 문서 — 문서를 만든 사람이 암호를 걸었습니다. 암호를 풀어 저장한 파일을 다시 받아야 합니다
  • 배포용 문서 — 읽기 전용으로 잠긴 형식입니다. 일반 문서로 다시 저장해 달라고 요청해야 합니다
  • 파일이 덜 받아짐 — 메일이나 메신저에서 내려받다 끊긴 경우입니다. 크기가 0KB에 가깝다면 다시 받아 보세요

자주 묻는 것

hwpx를 hwp로 되돌릴 수 있나요?

이 사이트에서는 hwp 형식으로 되돌려 저장하는 기능을 제공하지 않습니다. hwp로 저장하려면 한컴오피스가 필요합니다. 다만 PDF나 Word로 바꾸는 것은 가능하고, 실제로 전달·보관 목적이라면 그편이 더 널리 열립니다.

확장자만 hwp로 바꾸면 열리지 않나요?

열리지 않습니다. hwp와 hwpx는 내부 구조가 아예 달라서, 이름만 바꾸면 오히려 손상된 파일로 인식됩니다. 확장자는 바꾸지 마세요.

어떤 게 hwpx인지 어떻게 아나요?

파일 이름 끝이 .hwpx이면 hwpx입니다. 윈도우에서 확장자가 숨겨져 있다면 탐색기의 「보기」에서 「파일 확장명」을 켜면 보입니다.

표와 이미지도 그대로 보이나요?

표는 셀 병합까지 유지되고 이미지도 함께 표시됩니다. 다만 차트·글맵시·OLE 개체는 지원하지 않고, 머리말·꼬리말·각주는 본문 흐름에 이어서 나옵니다.
